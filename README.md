# 협력 vs 배신 - 교실용 v3

## 이번 버전 변경점
1. 학생이 입장할 때 닉네임을 직접 입력합니다.
2. 학생 화면에 현재 상대방의 닉네임이 표시됩니다.
3. 1·2·3라운드 모두 매 라운드마다 전체 학생을 새로 무작위 매칭합니다.
4. 같은 방 안에서 닉네임 중복은 허용하지 않습니다.
5. 홀수 인원일 경우 각 라운드에 1명은 쉬게 됩니다.

## 실행
```bash
npm install
npm start
```
브라우저에서 http://localhost:3000 접속.
